# STEP Sem-3 Week 7 Solutions

Each problem is in its own Java package. Compile all source files from this
folder, for example:

```powershell
javac -d out (Get-ChildItem -Recurse -Filter *.java | ForEach-Object FullName)
```

The static helper methods required in the questions are placed on `Shape`,
`ExportManager`, `VehicleService`, `ArenaBattle`, and `HomeControlPanel`.
